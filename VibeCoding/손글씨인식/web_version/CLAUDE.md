# Handwritten Digit Recognition Project

## Project Overview
MNIST 데이터세트를 사용하여 손글씨 숫자(0~9)를 실시간으로 인식하는 데스크톱 및 웹 애플리케이션입니다.

## Tech Stack
- Python 3.x
- scikit-learn (MLPClassifier)
- Pillow (Image Processing)
- Tkinter (Desktop GUI)
- Flask (Web Server)

## Commands
- 패키지 설치: `pip install -r requirements.txt`
- 데스크톱 버전 실행: `python desktop_version/digit_recognition.py`
- 웹 버전 실행: `python web_version/app.py`
