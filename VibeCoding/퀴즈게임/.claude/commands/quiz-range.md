`quiz-data.js` 파일을 읽고, $1번부터 $2번까지의 문제를 검토해 줘.
(번호는 문제의 `id` 기준. $1 또는 $2가 비어 있으면 전체 문제를 대상으로 해.)

각 문제에 대해:
1. 문제 번호, 카테고리, 난이도
2. 문제 내용
3. 정답 보기 번호(1~4)와 정답 내용

## 분석 항목
### 1. 난이도 분석
- 난이도를 점수로 환산(easy=1, medium=2, hard=3)해서 **평균과 표준편차**를 계산해.
- easy / medium / hard 개수와 비율을 보여 줘.
- 너무 쉽거나 어려운 문제가 특정 구간(연속된 번호)에 몰려 있는지 확인해.

### 2. 정답 분포 분석
- 정답이 1번, 2번, 3번, 4번 보기에 각각 몇 개인지 표로 보여 줘.
- 이상적인 분포(각 25%)와 비교해 치우침이 있는지 판단해.
  (예: 정답이 1번에 지나치게 몰리거나, 4번이 거의 정답이 아닌 경우)
- 같은 번호가 3번 이상 연속으로 정답인 구간이 있는지도 확인해.

### 3. 개선 제안
- 난이도 밸런스와 정답 위치를 고르게 맞추기 위한 구체적인 수정 방향을 제시해.
- 보기 순서를 바꾸는 경우 해설(explanation)과 모순이 없는지 함께 확인해.
- 파일은 사용자가 요청할 때만 수정해.
