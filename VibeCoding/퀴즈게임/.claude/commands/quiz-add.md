`quiz-data.js`에 새 퀴즈 문제를 1개 추가해 줘.

- 카테고리: $1  (한국사 | 세계지리 | 과학 | 예술과 문화 중 하나)
- 난이도: $2  (easy | medium | hard, '쉬움/보통/어려움' 또는 '초급/중급/고급'으로 입력하면 각각 easy/medium/hard로 변환)
- 카테고리나 난이도가 목록에 없으면 추가하지 말고 사용법을 안내해 줘.
  사용법: `/quiz-add [카테고리] [난이도]` (예: `/quiz-add 한국사 medium`, `/quiz-add 과학 hard`)

## 작성 규칙
1. 기존 문제와 **같은 형식**으로 작성해:
   `{ id, category, difficulty, question, options(4개), answer(0~3), explanation, hint }`
2. `id`는 현재 가장 큰 id + 1 로 지정하고, `QUIZ_DATA` 배열의 마지막에 추가해.
3. 기존 문제와 내용이 겹치지 않는지 먼저 확인해.
4. CLAUDE.md의 **퀴즈 문제 교차 검증 가이드라인을 반드시 지켜**:
   - 정답이 하나뿐인가? (다른 해석이 가능하면 조건 명시)
   - 최상급 표현('가장', '최초', '최대')에는 측정 기준 명시
   - 변할 수 있는 정보는 시점, 지리적·분류적 범위 명시
   - 확실하지 않은 정보는 사용하지 말고, 논란이 있으면 주류 학설 기준 + 해설에 다른 주장 안내
5. 정답 위치(answer)는 기존 정답 분포를 확인해서 **가장 적게 쓰인 번호**로 배치해.
6. 오답 보기는 그럴듯하지만 명확히 틀린 것으로 구성해.
7. 힌트는 정답을 직접 말하지 않도록 작성해.

## 출력
- 추가한 문제 전체 내용
- 가이드라인 4개 항목별 점검 결과 (✅/⚠️)
- 추가 후 카테고리별 문제 수와 정답 분포
