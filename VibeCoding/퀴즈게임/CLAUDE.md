# 지식왕 도전 (Knowledge King Challenge) - 상식 퀴즈 게임

4지선다 상식 퀴즈 웹 게임입니다.

## Project Overview
- 4개 카테고리(한국사, 세계지리, 과학, 예술과 문화) 각 10문제 + `/quiz-add`로 추가한 문제
- 정답/오답 즉시 피드백, 최종 점수와 카테고리별 결과, 순위(명예의 전당) 기록
- 게임 모드: 전체 도전 / 카테고리별(10문제) / 스피드 퀴즈(20문제, 문제당 15초)

## Commands
- 실행: `index.html` 더블 클릭 (빌드·설치 불필요)
- 커스텀 명령어 (`.claude/commands/`)
  - `/quiz-validate [카테고리]` : 최상급 표현 등 검증 가이드라인 위반 점검
  - `/quiz-range [시작] [끝]` : 지정 범위 문제의 난이도·정답 분포 분석
  - `/quiz-add [카테고리] [난이도]` : 가이드라인을 지킨 새 문제 추가

## Tech Stack
- Vanilla JavaScript (ES6+), HTML5, CSS3 — 외부 라이브러리 없음
- 순위 저장: localStorage (`quiz.rankings`)

## Architecture
- `index.html`   : 화면 5개 (시작 / 모드 선택 / 퀴즈 / 결과 / 명예의 전당) + 피드백 오버레이
- `style.css`    : 보라색 그라데이션 테마, 반응형
- `quiz-data.js` : 문제 데이터 `QUIZ_DATA`, 카테고리 정보 `CATEGORY_META`
- `script.js`    : 게임 로직 (IIFE)
  - `ScoreManager` : 점수 계산 (기본 10점 × 난이도 배수 easy 1 / medium 1.5 / hard 2,
    10초 미만 +3, 힌트 미사용 +2, 콤보 3연속 +2 · 5연속 +5 · 10연속 +10, 힌트 사용 −2)
  - `startGame / renderQuestion / answer / next / showResult / saveRank`

### 문제 데이터 형식
```js
{
  id: 1,                       // 고유 번호 (마지막 번호 + 1로 추가)
  category: '한국사',           // 한국사 | 세계지리 | 과학 | 예술과 문화
  difficulty: 'easy',          // easy | medium | hard
  question: '임진왜란이 일어난 연도는?',
  options: ['1392년', '1592년', '1636년', '1910년'],
  answer: 1,                   // options 인덱스 (0~3)
  explanation: '정답 해설',
  hint: '힌트 (정답을 직접 말하지 않기)',
}
```

## Code Style
- 코드 식별자는 영어 camelCase, 주석·UI 문구·문제는 한국어
- 사용자 입력(이름)은 `escapeHTML()`로 출력
- 보기 순서는 셔플하지 않음 (정답 위치 분포를 데이터에서 직접 관리)

## Development Notes
- 정답 위치가 특정 번호에 몰리지 않도록 0~3이 고르게 분포하도록 유지
- 문제를 추가·수정하면 반드시 아래 가이드라인으로 점검할 것

# 퀴즈 문제 교차 검증 가이드라인

**중요: 모든 문제 작성·수정 시 반드시 확인**

모든 문제 작성 시 확인 사항
1. 정답이 하나뿐인가?
   - 다른 해석 가능 시 조건 명시 (예: 면적 기준, 2024년 기준)

2. 최상급 표현에 기준이 있는가?
   - '가장 큰', '최초의' 등 표현에 측정 기준 명시

3. 시간과 범위가 명확한가?
   - 변할 수 있는 정보는 시점 명시
   - 지리적, 분류적 범위 한정

4. 교차 검증했는가?
   - 의심스러운 정보는 2개 이상 출처 확인
   - 논란 있는 내용은 주류 학설 기준
   - 논란이 있으면 해설(explanation)에 다른 주장도 함께 안내
     (예: 나일강 문제 → "최근 연구에서는 아마존강이 더 길다는 주장도 있습니다")

5. 출처 없는 정보는 생성하지 말 것
