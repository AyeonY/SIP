# 상식 퀴즈 게임 PRD (Product Requirements Document)

> 클로드(claude.ai)에 아래 프롬프트를 입력해 작성한 제품 기획서입니다.
> ```
> 상식 퀴즈 게임을 만들려고 해. PRD를 작성해 줘.
>
> 게임 규칙:
> - 4지선다 객관식 퀴즈
> - 카테고리: 한국사, 과학, 지리, 일반상식
> - 각 카테고리별 10문제씩 총 40문제
> - 정답/오답 즉시 피드백
> - 최종 점수 및 순위 기록
> ```

## 1. 프로젝트 개요
### 1.1 제품명
지식왕 도전 (Knowledge King Challenge)

### 1.2 제품 목적
다양한 분야의 상식을 재미있게 학습하고 테스트할 수 있는 4지선다 퀴즈 게임을 개발하여 사용자의 지식 습득과 두뇌 활동을 촉진한다.

### 1.3 타깃 사용자
- 연령: 중학생 이상 (14세+)
- 특징: 상식 퀴즈와 학습에 관심이 있는 사용자
- 이용 환경: 모바일/웹 브라우저

## 2. 핵심 기능 요구사항
### 2.1 게임 구조
- 총 40문제 (한국사 10, 세계지리 10, 과학 10, 예술과 문화 10)
- 4지선다 객관식
- 카테고리 순서대로 출제

### 2.2 피드백
- 보기 선택 즉시 정답/오답 판정
- 정답은 초록색, 선택한 오답은 빨간색으로 표시
- 해설 팝업과 [다음 문제] 버튼

### 2.3 결과 및 순위
- 최종 점수, 정답 개수, 정답률, 카테고리별 결과
- 이름을 입력해 순위(Top 10) 기록 — localStorage

## 3. 확장 기능 (2단계)
- 점수 시스템: 난이도 배수(easy 1x, medium 1.5x, hard 2x), 시간 보너스(10초 미만 +3), 힌트 미사용 보너스(+2), 연속 정답 콤보(3연속 +2, 5연속 +5, 10연속 +10)
- 게임 모드: 전체 도전(40문제) / 카테고리별(10문제) / 스피드 퀴즈(20문제, 문제당 15초)
- 힌트: 오답 2개 제거 + 힌트 문구, 2점 차감

## 4. 콘텐츠 품질 (할루시네이션 방지)
- 모든 문제는 CLAUDE.md의 교차 검증 가이드라인을 통과해야 함
- 최상급 표현에는 측정 기준 명시, 논란 있는 내용은 주류 학설 + 부가 설명

## 5. 기술 스택
- Vanilla JS + HTML/CSS (설치 없이 `index.html` 실행)
- 문제 데이터 분리: `quiz-data.js`

## 6. 개발 단계 (Claude Code 3단계 프롬프트)
1. **1단계 – 핵심 퀴즈 시스템 구축 (MVP)**: 문제 데이터 구조, 출제, 정답 판정, 즉시 피드백, 결과 화면
2. **2단계 – 게임 확장**: 점수 시스템(ScoreManager), 게임 모드 3종, 힌트, 순위
3. **3단계 – 품질 검증 및 자동화**: 교차 검증 가이드라인(CLAUDE.md), 커스텀 명령어 `/quiz-validate`, `/quiz-range`, `/quiz-add`
