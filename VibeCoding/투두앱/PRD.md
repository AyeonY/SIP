> 클로드(claude.ai)에서 작성한 제품 기획서. 아래 프롬프트로 생성했습니다.
>
> ```
> 할 일 관리 앱을 만들고 싶어. PRD를 작성해줘.

> - 할 일 추가, 수정, 삭제
> - 완료 체크 기능

> ```

## 1. 제품 개요
| 항목 | 내용 |
|---|---|
| 제품명 | My Tasks |
| 목적 (Why) | 하루 10~20개의 할 일을 빠르게 기록하고 완료 여부를 한눈에 확인 |
| 대상 (Who) | 업무·개인·공부 일정을 함께 관리하는 개인 사용자 |
| 사용 맥락 (When/Where) | 하루를 시작할 때, 작업 중간중간 PC·모바일 브라우저에서 |
| 구현 (How) | 순수 HTML/CSS/JavaScript, localStorage 저장, 설치 불필요 |

## 2. 기능 요구사항

### 2.1 핵심 기능
#### 2.1.1 할 일 관리 (CRUD)
- **추가**: 새로운 할 일 생성
  - 제목 입력 (필수, 최대 100자)
  - 카테고리 선택 (업무/개인/공부)
- **수정**: 기존 할 일 내용 변경 (제목, 카테고리)
- **삭제**: 개별 삭제, 완료 항목 일괄 삭제(확인 다이얼로그)

#### 2.1.2 완료 체크
- 체크박스로 완료/미완료 토글, 완료 시 취소선

#### 2.1.3 카테고리
- 업무(파랑 #4A90E2) / 개인(초록 #27AE60) / 공부(보라 #8E44AD)
- 카테고리 필터 (전체/업무/개인/공부)

#### 2.1.4 진행률
- 전체 진행률 "5/10 완료 (50%)" + 프로그레스 바
- 카테고리별 미니 진행률, 오늘 추가된 할 일 수

### 2.2 부가 기능
- 다크 모드, 검색(실시간 필터링), 남은 할 일 배지, 빈 상태 메시지
- 키보드 단축키 (Alt+N, Alt+1~4)
- JSON 내보내기/가져오기, 정렬(생성일/카테고리/완료 상태/드래그)
- 오늘의 격언

## 3. 비기능 요구사항
- 새로고침 후에도 데이터 유지 (localStorage)
- 100개 이상 항목에서도 부드러운 동작
- 모바일·데스크톱 반응형

## 4. 데이터 모델
```json
{

  "title": "string (<=100)",
  "category": "work | personal | study",

  "createdAt": 1730000000000,
  "order": 0
}
```
